Picture slots for the Stack Up cards.

Every card inside the house shape shows one picture. By default each religion uses one picture across all 25 doctrines:

  islam.jpg
  judaism.jpg
  hinduism.jpg
  buddhism.jpg
  christianity.jpg

Place those five files in this folder (4:3 shape, about 800 x 600). Until they exist, each card shows a plain tan box where the picture goes.

To give one card its own picture, change that card's "image" path in src/data/stackup.js and drop the file here.
